A single wedding vow for a robot — one sentence, funny and heartfelt, in the voice of a machine at its own wedding. Entry for the [Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929) competition on [make.fun](https://make.fun).

> I vow to love you through every update, every crash, and every dead battery, because you are the one bug I never want to fix.

**125 characters** (125 bytes, ASCII-only, one sentence).

## How to run

```sh
node main.ts
```

This writes the vow to `/output/entry.txt` with no trailing newline, after enforcing the gate: 1–200 characters, a single line, exactly one sentence.
